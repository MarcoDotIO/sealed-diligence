# Sealed Diligence brand

**Idea.** Tamper-evident security tape. Intact tape means nothing was opened; peeled tape shows VOID. That is the product: a diligence report you can trust because any edit breaks the seal.

**The one loud element** is the tape strip: a full-bleed band at about −2°, printed in wide caps with the real request id, commit and enclave key. Cobalt when verified, red with a faint VOID pattern when anything fails. Everything else stays quiet and left-aligned.

## Color

| Token | Light | Dark | Use |
|---|---|---|---|
| paper | `#E8EBEE` | `#15171B` | page (cool, like poly evidence bags) |
| sheet | `#F6F7F8` | `#1C1F25` | rare raised surfaces, logo document |
| ink | `#1E2128` | `#E6E8EC` | text, rules, primary button |
| muted | `#5B6270` | `#9AA1AD` | secondary text |
| rule | `#C8CDD4` | `#2E333B` | hairlines, empty meters |
| cobalt | `#2443C9` | `#4D6CFF` | intact seal, links, focus |
| void | `#CC2A2F` | `#FF5A5F` | broken seal, failures, "do not proceed" |
| pass | `#1D7A4C` | `#4CC38A` | passed checks, "proceed" |

## Type

Archivo, one family, using its width axis (self-hosted `assets/archivo.woff2`).
- Display and tape: width 125, weight 760–800, tight tracking. Tape text is the only place caps are used.
- Body: width 100, weight 400, 17px/1.55.
- Hashes and file paths only: system monospace.

## Mark

`assets/mark.svg`: a document crossed by a strip of cobalt tape with perforation ticks. Works at 16px.

## Don'ts

No eyebrow labels, no gradients, no card grids, no wax seals, no `→` on links, no middle-dot meta strings in UI copy.
